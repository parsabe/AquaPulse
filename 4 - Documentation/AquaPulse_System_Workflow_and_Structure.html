Executive Overview

Underwater optical imaging presents unique physical challenges: extreme light absorption (red wavelengths decay within 5 meters), forward and backward scattering causing severe blur, and dynamic background clutter (aquatic vegetation, sand beds). The AquaPulse system bridges field video collection and deep neural analytics through a modular two-tier architecture:

  • Phase 0 — Preprocessing Pipeline: Handles raw dual-fisheye 360° Insta360 video conversion, frame extraction, YOLOv8 aquatic target filtering, 512x512 CUDA resolution normalization to prevent VRAM Out-Of-Memory (OOM) failures, and Multi-Scale Retinex with Color Restoration (MSRCR) dehazing.
  • Phase 3 — AI Inference & Telemetry Engine: Houses the real-time Cyberpunk HUD, Vision Transformers (ViT), ByteTrack multi-object tracking, Bayesian Neural Networks (BNN), Domain Adversarial Neural Networks (DANN), live GBIF taxonomy retrieval, and Dr. Daniel Pauly persona LLM voice synthesis.

Phase 0: Preprocessing Pipeline Breakdown

2.1. Dual-Fisheye to Rectilinear MP4 Conversion (insv_mp4.py)

Raw recordings from Insta360 cameras are saved in .insv dual-fisheye format with extreme circular distortion. The script insv_mp4.py converts dual-fisheye frames into standard rectilinear 1920x1080 30FPS MP4 videos using CUDA hardware acceleration.

Equidistant Fisheye Projection Formula:
r_fish = (2 * R / π) * θ | where θ = arctan(√(x² + y²)), f = (W_out / 2) / tan(FOV_x / 2)
PyTorch Grid Sample Mapping: torch.nn.functional.grid_sample(frame_tensor, grid, mode='bilinear')
2.2. Frame Extraction Process (1 - all_frames.py)

Extracts all frames recursively from converted videos using OpenCV VideoCapture. Frames are assigned directory-based prefixes and stored as zero-padded sequential image files (<prefix>_frame_000123.jpg) in the All Frames directory.

2.3. YOLO-Based Fish Frame Filtering (2 - only_fish_frames.py)

Underwater field videos contain vast spans of empty water without fish. Including background frames introduces severe noise into training. The script 2 - only_fish_frames.py runs batch inference (batch size = 32) using CUDA-accelerated yolov8n.pt. Only frames containing detected aquatic organisms (fish class) are copied into Extracted fish objects in frames.

2.4. Spatial Normalization & 512x512 Resizing to Prevent OOM (3 - resize.py)

High-resolution frames (1080p / 4K) trigger severe GPU VRAM memory exhaustion during multi-epoch neural training and Vision Transformer attention calculations, leading to fatal Out-Of-Memory (OOM) crashes.

  • CUDA Tensor Interpolation: Converts image arrays to PyTorch CUDA float32 tensors and applies torch.nn.functional.interpolate(tensor, size=(512, 512), mode='bilinear').
  • Memory Efficiency: Standardizing all images to 512x512 strictly constrains VRAM allocation per batch while preserving vital morphological features (scale textures, fin geometry, body proportions) required for species identification.
2.5. Underwater Image & Video Dehazing — MSRCR Method

To restore underwater visibility, AquaPulse applies Multi-Scale Retinex with Color Restoration (MSRCR) across images and batch video streams.

Retinex Illumination Model: I(x,y) = R(x,y) · L(x,y) ⇒ log₁₀ R(x,y) = log₁₀ I(x,y) - log₁₀ L(x,y)
Multi-Scale Gaussian Surround: R_MSR = (1/3) ∑ [ log₁₀ I(x,y) - log₁₀ (F_k(x,y) * I(x,y)) ] for σ ∈ {15, 80, 250}
Color Restoration Weight: C_i(x,y) = log₁₀(125 · I_i(x,y)) - log₁₀(∑ I_channels)
Final MSRCR output: R_MSRCR,i(x,y) = C_i(x,y) · R_MSR,i(x,y)

GPU Speedup: Computed using separable 1D Gaussian kernels on PyTorch CUDA GPU tensors, achieving 30+ FPS real-time dehazing with FFmpeg audio preservation.

03

Phase 3: AI Process & Neural Telemetry Engine

3.1. Cyberpunk HUD Telemetry Engine (main.py)

The primary engine main.py combines real-time vision analytics with a Cyberpunk-inspired graphical HUD. It features automatic cross-platform hardware detection (NVIDIA CUDA, Apple MPS, AMD DirectML, CPU fallback), animated scanlines, corner reticles, confidence meters, and interactive target locks.

3.2. Vision Transformers (ViT), Bayesian Networks (BNN), & Domain Adaptation (DANN)

To maintain robust classification accuracy across murky river channels and clear tank environments:

  • Vision Transformers (ViT): Splits 512x512 fish images into 16x16 visual patches, leveraging self-attention mechanisms to learn fine-grained species patterns (fin structures, body striping).
  • Bayesian Neural Networks (BNN): Implements Gaussian weight distributions (μ, ρ) using the reparameterization trick. Computes Evidence Lower Bound (ELBO) loss and KL divergence to quantify epistemic uncertainty for rare species.
  • Domain Adversarial Training (DANN): Employs a Gradient Reversal Layer (GRL) between the YOLO feature extractor and domain classifier. Reversing gradients (-α) forces the backbone to learn domain-invariant representations that bridge clear tank datasets and turbid Spreewald field footage.
3.3. Multi-Object Tracking & Target Lock (ByteTrack / BoTSORT)

Integrates Kalman filtering and Hungarian matching (ByteTrack/BoTSORT) to assign persistent track IDs to swimming fish. Includes a sticky target lock mechanism (update_sticky_target_lock) with spatial Euclidean distance matching and lost-frame memory buffers to eliminate identity swaps.

3.4. GBIF & Wikimedia Taxonomic Knowledge Retrieval

When a target is locked, main.py queries the Global Biodiversity Information Facility (GBIF Match & Occurrence API) for scientific taxonomy (Kingdom, Phylum, Class, Order, Family, Genus, Species). Reference photos are fetched from GBIF and Wikimedia Commons, then stored in a persistent local disk cache (species_snapshots/wiki_cache/) for offline operation.

3.5. Local LLM Telemetry Agent (Ollama LLM - Llama 3) & Multi-Lingual Voice Synthesis

AquaPulse integrates a local LLM agent via Ollama (Llama 3) assuming the persona of marine biologist Dr. Daniel Pauly. The LLM synthesizes GBIF taxonomy into concise scientific explanations capped at 40 words. Voice output is rendered by CancellableAudioEngine (pyttsx3) in English or German, equipped with mutual exclusion locks to prevent speech overlap.
